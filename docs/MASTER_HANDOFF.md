GoRouter auth guard, Drift cache-then-remote, AuthRepositoryFake, widget tests.

## 4. ARCHITECTURE DECISIONS

| Decision | Current implementation | Reason |
|----------|------------------------|--------|
| Feature-first | `lib/features/*` (data/domain/presentation) | autonomy, scalability |
| Repository Law | Widget/Provider → Repository → Datasource → Remote/Local | swap backend without UI rewrite |
| Riverpod 3 | Notifier/AsyncNotifier, ref.watch DI | state + DI, no GetIt/Bloc |
| GoRouter | declarative + `appRouterRedirect` auth guard | route protection |
| Freezed | DTOs (Product, AuthState) | JSON codegen |
| Equatable | User, DashboardState | security toJson (excludes password/token) + 119→115 tests green |
| Networking | Dio + NetworkService abstraction | vendor swap |
| Drift + SQLite | `lib/core/database/`, cache-then-remote | local persistence |
| Preferences | shared_preferences (UI-only settings) | lightweight KV |
| Authentication | AuthRepository contract + Fake/Impl | provider-independent |
| Feature boundaries | `tool/check_boundaries.dart` CI guard | prevent cross-feature import |
| Shared boundaries | `shared/` = generic primitives ONLY (leak fixed this iter) | no feature coupling |
| Service contracts | abstract + Noop | vendor independence |
| Package readiness | `docs/PACKAGE_EXTRACTION.md` (plan, not extracted) | monorepo OK for template |
| Feature flags | `FeatureFlags` + Static/RemoteConfig impls | vendor-independent |
| Observability | Analytics/Crash/Perf/Logger contracts (Noop) | swap vendor later |
| Environments | DEV/STAGING/PROD via `--dart-define` BASE_URL_* (fixed this iter) | honest separation |
